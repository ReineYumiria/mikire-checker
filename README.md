# 見切れチェッカー

画像をアップロードして、各サービス用の画像サイズ・安全領域・円形アイコン表示を確認できるWebツールです。

YouTubeサムネイル、X（旧Twitter）ヘッダー、Bluesky、Misskey、Discordアイコン、Steamカプセル、SoundCloudアートワーク、pixiv/FANBOXカバーなど、創作・配信・ゲーム制作・SNS・音楽活動向けの画像確認に使えます。

公開URL：

https://mikire-checker.vercel.app/

## 特徴

- 画像はサーバーに送信されず、ブラウザ内だけで処理されます
- サービスをカテゴリ別に選択できます
- 各サービス向けの画像サイズをプリセットから選択できます
- 安全領域ガイドを表示できます
- 円形アイコン表示の見切れを確認できます
- 画像をドラッグして位置調整できます
- ズーム調整ができます
- マウスホイールでズームできます
- スマホではピンチズームに対応しています
- PNGとして書き出せます
- ガイド付きPNGとしても書き出せます
- PC / スマホの両方で利用できます
- YouTube サムネイル選択時にホーム風カードプレビューを表示できます（試作）
- 収益化準備として広告枠を設置しています（`AdSlot` コンポーネント経由で管理）
- 開発環境や広告表示用の環境変数未設定時はプレースホルダー表示になります
- AdSense 所有権確認用の client ID は `NEXT_PUBLIC_GOOGLE_ADSENSE_CLIENT` で管理します
- Google AdSense のサイト所有権確認済み・審査リクエスト済み（現在審査待ち）
- 実広告はまだ表示していません。実広告の有効化・ads.txt は v1.10.0 以降で対応予定です
- About / 使い方 / プライバシーポリシーのサイト内ページを提供しています
- sitemap.xml / robots.txt を自動生成しています

## 使い方

1. 「画像を選択」から画像ファイルをアップロードします
2. 「対象サービス」を選択します
3. 「用途プリセット」を選択します
4. プレビュー上で画像をドラッグして位置を調整します
5. ズームスライダー、マウスホイール、またはスマホのピンチ操作で拡大縮小します
6. 必要に応じて安全領域ガイドを確認します
7. PNGとして書き出します

## 書き出しについて

通常のPNG書き出しに加えて、確認用としてガイド付きPNGを書き出すこともできます。

- PNG書き出し：最終画像確認用
- ガイド付きPNG書き出し：安全領域や円形ガイドを含めた確認用

## 対応画像形式

- PNG
- JPG / JPEG
- WebP

## プライバシー

アップロードした画像はサーバーに送信されません。

画像の読み込み、位置調整、ズーム、プレビュー、PNG書き出しはすべてブラウザ内で処理されます。

詳しくはサイト内の [プライバシーポリシー](https://mikire-checker.vercel.app/privacy) または `PRIVACY.md` を確認してください。

## 注意事項

各サービスの画像サイズや表示仕様は、サービス側の更新によって変更される可能性があります。

また、BOOTH / Ci-en / Skeb / Misskey など一部のプリセットは、公式に明確な推奨サイズが確認しづらいものや、インスタンスやテーマによって表示が異なる場合があるものを含むため、「目安」として扱っています。

安全領域は、重要な文字・顔・ロゴなどを端に寄せすぎないための確認用ガイドです。実際の表示環境や端末によって、見え方が変わる場合があります。

縦長画像のプリセットでは、PC表示時にプレビュー領域が縦に長く表示されることがあります。スマホ向け画像の確認を優先した仕様です。

サイト表示風プレビュー（YouTube ホーム風）は試作機能です。YouTube の実際の表示とは異なる場合があります。
