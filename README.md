# 見切れチェッカー

画像をアップロードして、各サービスでの表示範囲や安全領域を確認できるWebツールです。

YouTube、Twitter、Discord、note などのヘッダー画像・アイコン画像・投稿画像が、実際の表示で見切れないかをブラウザ上で確認できます。

## 公開URL

https://mikire-checker.vercel.app/

## 特徴

* 登録不要
* 画像はサーバーに送信しない
* ブラウザ内だけで画像を処理
* 各サービスの表示プレビューに対応
* 安全領域ガイドを表示
* 円形アイコンガイドを表示
* ドラッグで位置調整
* ズーム調整
* PNG書き出し
* ガイド付きPNG書き出し

## 使い方

1. 画像をアップロードする
2. 対象サービスを選ぶ
3. 用途プリセットを選ぶ
4. プレビューで見切れや安全領域を確認する
5. 必要に応じて画像の位置やズームを調整する
6. PNGとして書き出す

## 画像の扱いについて

アップロードした画像はサーバーに送信されません。

画像の読み込み、プレビュー、位置調整、書き出しはすべてブラウザ内で行われます。

## 主な機能

* 画像アップロード
